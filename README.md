# 📚 Student Library System

A CLI-based Library Management System built using Python (OOP) with local JSON data persistence.

---

## ✨ Features
* ➕ **Add Books:** Add new books with unique ID, Title, and Author.
* 📖 **View Books:** View all books with live status (Available / Issued to student).
* 🔄 **Issue & Return Books:** Track book issuance and return states dynamically.
* 🔍 **Search Books:** Fast case-insensitive search by ID, Title, or Author.
* 🗑️ **Delete Books:** Remove available books safely from the database.
* 💾 **Data Persistence:** Automatic state saving and loading via `books.json`.

---

## 🛠️ Tech Stack
* **Language:** Python 3
* **Storage:** JSON
* **Concepts:** Object-Oriented Programming (OOP), File I/O, Data Validation
* **Version Control:** Git & GitHub
